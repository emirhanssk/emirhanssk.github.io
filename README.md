# Emirhan Köse — Game Development Portfolio

An English portfolio covering Fallune!, Battle Orders and Cities Tycoon. Built with accessible, responsive HTML, CSS and JavaScript. No build tools are required.

## Run

Serve `dist/` using any static HTTP server. For example: `python -m http.server 8000 --directory dist`.

The public GitHub Pages repository hosts the same files at its root. Screenshots can be enlarged with the mouse or keyboard; native details panels expose technical notes.

## Content basis

Project descriptions were reviewed against private source repositories on 11 October 2026. Game source code is not included or licensed by this portfolio.

- Fallune!: `PROJECT_MANUAL.md`, `Assets/Scripts/BoxSpawner.cs`.
- Battle Orders: current `AlayHareket.cs` and `Tools/verify/perf-probe/Program.cs`. Earlier movement documents were treated as historical.
- Cities Tycoon: progression and production documentation, `BuildController.Instancing.cs`, `GpuInstancedVisualProxy.cs`, `ChunkCullingController.cs` and `Simulation Manager.cs`.

Screenshots were supplied by the developer. FPS and profiler captures are development evidence, not universal benchmarks. Fallune's release status and store URL were supplied by the developer; the Google Play page could not be retrieved during preparation. The Fallune panel is a labelled graphic rather than a gameplay screenshot.
